## 先确认：IP真的被封了吗？

很多人一遇到连不上就断定IP被封，但实际上有几种情况长得很像：

- 本地网络问题（运营商临时抽风、DNS污染）
- 机器本身宕机或超载
- 端口被防火墙拦截（22/443/80各有不同表现）
- IP被封（GFW层面的封锁）

区分方法很简单。用手机4G热点（脱离家庭宽带环境）直接ping目标IP，如果还是不通，再用国外的在线ping工具（比如ping.pe）测同一个IP——如果国外节点全部正常、国内全部超时，基本可以确认是GFW封锁，而不是机器问题。

SSH连不上但ping有回包，通常是端口问题，改端口就能解决，不需要换IP。

## IP被封之后，DMIT能做什么

### 换IP这件事，没有统一答案

DMIT官方的换IP政策按套餐和情况不同而不同，不存在"免费无限换"这种好事。

我自己的经历是：提工单说明IP被封，附上ping.pe的截图作为证明，客服响应速度还算正常。但换IP通常是收费的，具体金额看套餐，Premium套餐的换IP费用比Lite贵。

有几点要注意：

1. 工单里直接说"IP被GFW封锁，附截图"，不要绕弯子，客服看得懂
2. 换IP不保证新IP不被封，这是概率问题，不是承诺
3. 部分套餐支持自助换IP（控制面板里有选项），不需要等工单

### 换机房或换套餐

如果某个地区的IP段最近被集中清洗，换IP也只是换了一个同样高风险的地址。这种情况下，换机房（比如从香港换到日本或美西）是更彻底的解法。

DMIT支持在不同套餐之间升降级，但跨地区迁移通常需要重新购买，原套餐退款按剩余时间折算。

### 临时方案：端口转发和反代

IP被封但机器还活着的情况下，可以通过另一台没被封的机器做端口转发，把流量中转过去。这不是DMIT提供的功能，是你自己在服务器层面操作的——但DMIT的机器支持这么做，没有限制。

## 降低被封概率的几个实操习惯

被封之后换IP是被动应对，主动降低风险才是正解。我自己用下来，有几个习惯确实有效：

**不要在IP上直接跑高风险流量。** 如果你的机器同时承担多种用途，把敏感流量和普通业务分开，用不同的端口甚至不同的机器隔离。一个IP被封，不至于全线瘫痪。

**定期检查IP的封锁状态。** 不要等到用不了才发现。可以设置一个简单的监控脚本，每隔几分钟从国内节点ping一次，异常就发通知。

**选Premium线路，不要为了省几块钱选Lite。** Lite的IP段被封的频率明显更高，换IP的成本加起来早就超过Premium的差价了。这是我自己算过账的结论。

**年付要谨慎。** IP被封的风险是客观存在的，年付锁定了一整年，如果这个地区的IP段持续被清洗，你的损失会更大。月付灵活性更高，尤其是第一次用某个地区的节点时。

## FAQ

### DMIT的IP被封了，能免费换吗？

不一定免费。DMIT的换IP政策是收费的，具体金额取决于套餐类型。提工单时附上IP被封的证明（ping.pe截图），客服会告知换IP的费用和流程。部分套餐控制面板里有自助换IP选项，可以先检查一下。

### Premium线路的IP就不会被封吗？

会封，只是概率低一些。CN2 GIA的IP段质量更好，但GFW的封锁没有绝对的豁免。Premium线路的优势在于：IP池质量更高、被集中清洗的频率更低、出了问题客服处理优先级更高。

### 香港、日本、美西，哪个地区的IP最不容易被封？

没有绝对答案，跟时间段和IP段的使用历史都有关系。从我自己的使用经验来看，日本节点在某些时期比香港稳定，但香港的延迟优势明显。如果你的业务对延迟不敏感，美西Premium也是一个分散风险的选项。

### IP被封之后，机器上的数据还在吗？

在的。IP被封只是网络层面的封锁，机器本身还在正常运行，数据不受影响。你可以通过VNC控制台（DMIT后台提供）访问机器，或者通过另一台没被封的机器做跳板连进去。

### DMIT支持退款吗？

DMIT有退款政策，新购套餐在一定时间内可以申请退款，具体条款以官网为准。如果是因为IP被封导致服务不可用，可以在工单里说明情况，客服会根据实际情况处理。

### 换了新IP之后，怎么降低再次被封的风险？

换IP之后，避免立刻在新IP上跑高风险流量。给新IP一个"冷却期"，先用普通业务跑一段时间，确认稳定之后再逐步迁移其他用途。同时做好监控，一旦发现封锁迹象立刻处理，不要等到完全不可用。
